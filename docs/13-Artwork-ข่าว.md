# Artwork ข่าว iHC-Press: ภาพจาก Flow + ข้อความไทยที่ใส่เอง

> อัปเดต 2026-10-17 · โค้ดอยู่ใน `iHC-Press\tools\news-art\` · prompt อยู่ใน [`prompt/news-art.json`](prompt/news-art.json)

## 1. ทำไมต้องแยก 2 ชั้น

| ชั้น | ใครทำ | ทำไม |
|---|---|---|
| **ภาพ** (ภาพประกอบ, เฟรมขอบ, พื้นผิว) | Google Flow · Nano Banana 2.1 (ฟรี) | ภาพ 3D สวยและคุมโทนแบรนด์ได้ แต่ **สะกดตัวอักษรไทยผิด** จึงสั่งทุกภาพว่า "no text" |
| **ข้อความ** (หัวข่าว, ป้ายสายข่าว, วันที่, ที่มา, โลโก้) | เทมเพลต HTML + ฟอนต์ Noto Sans Thai แล้วใช้ Edge แบบ headless ถ่ายเป็น PNG | ตัวอักษรเป็นฟอนต์จริง สระและวรรณยุกต์ถูกต้อง 100% แก้คำได้ทันทีโดยไม่ต้องสร้างภาพใหม่ |

ก่อนหน้านี้ iHC-Press **ยังไม่มีการทำภาพ** ฝ่ายภาพเขียนได้แค่ "บรีฟภาพ" (ข้อความในช่อง `image` ของข่าว) เครื่องมือนี้คือขั้นแรกที่เปลี่ยนข่าวให้เป็นภาพพร้อมโพสต์

## 2. แบบ (variant) × ขนาด (format)

| variant | ใช้เมื่อ | หน้าตา |
|---|---|---|
| `photo` (ค่าเริ่มต้น) | ข่าวทั่วไป | 16:9 ภาพเต็มกรอบ ไล่เงาดำด้านล่าง หัวข่าวมีแถบแดงด้านซ้าย · 1:1 และ 4:5 ภาพอยู่บน ข้อความอยู่บนแผงดำลายวงจร |
| `breaking` | ข่าวด่วน | พื้นหลังเส้นแสงแดงวิ่ง ป้ายขาว "ข่าวด่วน" ภาพประกอบอยู่ในการ์ดขอบแดงเรืองแสง |
| `card` | สรุป/อธิบาย ไม่ต้องมีภาพข่าว | พื้นลายวงจร หัวเรื่องใหญ่ และ bullet สูงสุด 3 ข้อ (`--points`) |

| format | ขนาด (px) | ใช้ที่ |
|---|---|---|
| `16x9` | 1600×900 | ภาพปกข่าว, ลิงก์ Facebook, X, เว็บ |
| `1x1` | 1080×1080 | โพสต์ Facebook/IG/LINE |
| `4x5` | 1080×1350 | โพสต์แนวตั้ง Facebook/IG (ได้พื้นที่บนฟีดมากที่สุด) |

องค์ประกอบที่ทุกภาพมี: wordmark **iHC-Press** (i กับ C สีแดง ล้อโลโก้ iHAVECPU), คำบรรยาย "ข่าวเทคโนโลยีและคอมพิวเตอร์", วันที่แบบไทย (พ.ศ.), ป้ายสายข่าวสีแดง `#C81E23`, "ที่มา: <โดเมนแหล่งแรก>" และ "iHC-Press · ในเครือ iHAVECPU"

## 3. วิธีใช้

```powershell
cd D:\SalmonRK\BotPress\iHC-Press
# จากข่าวในโต๊ะข่าว: ดึงหัวข่าว สายข่าว ย่อหน้าแรก และแหล่งแรก จาก stories.json เอง
node tools\news-art\render.mjs --story 20261014-01
# ข่าวด่วน เฉพาะ 16:9 กับ 4:5
node tools\news-art\render.mjs --story 20261014-01 --variant breaking --formats 16x9,4x5
# ใช้ภาพของข่าวเอง (เช่น ภาพหน้าจอจาก YouTube digest หรือภาพ press kit) แทนภาพประจำสายข่าว
node tools\news-art\render.mjs --story 20261014-01 --art D:\AI-ART\BotPress\data\news\youtube\<id>\shot-01.jpg
# การ์ดสรุป ไม่ต้องมีข่าวในระบบ
node tools\news-art\render.mjs --id cpu-tips --variant card --beat other --headline "สรุป 3 เรื่องต้องรู้ ก่อนอัปเกรดซีพียู" --points "ข้อ 1|ข้อ 2|ข้อ 3" --source "ทีมข่าว iHC-Press"
```

- ผลลัพธ์อยู่ที่ `D:\AI-ART\BotPress\data\news\art\<id>\<variant>-<format>.png` (เปลี่ยนได้ด้วย `--out`)
- ตัวเลือกอื่น: `--dek` (คำโปรย), `--date`, `--source`, `--lines` (จำนวนบรรทัดหัวข่าว)
- **หัวข่าวยาว:** ระบบย่อฟอนต์ลงเองจนพอดี ถ้ายังยาวเกินจะจบด้วย "…" ไม่ตัดกลางบรรทัด
- **คำที่ห้ามตัด:** Chrome ตัดคำไทยด้วยพจนานุกรมซึ่งไม่รู้จักคำทับศัพท์หลายคำ (เคยตัดเป็น "อัป|เกรด") เทมเพลตจึงมีรายการคำที่ห้ามตัด (อัปเกรด ซีพียู การ์ดจอ เมนบอร์ด โน้ตบุ๊ก ฯลฯ) และครอบคำเองได้ด้วย `{...}` เช่น `--headline "เปิดตัว {Ryzen 9 9950X3D} ในไทย"`
- ต้องมี Microsoft Edge หรือ Chrome ในเครื่อง (ตั้ง `BROWSER=<path>` ได้) และ Node.js ฟอนต์ Noto Sans Thai (OFL) อยู่ใน `tools\news-art\fonts\` จึงทำงานได้แบบ offline

## 4. Asset จาก Flow (14 ภาพ ไม่มีตัวอักษร)

| id | ใช้กับ | เนื้อหา |
|---|---|---|
| `beat-ai` | สาย AI-โมเดล | สมองแสงแดงลอยเหนือชิป AI |
| `beat-gadget` | Gadget-มือถือ | มือถือพับได้ นาฬิกา หูฟัง ลอยบนพื้นมันดำ |
| `beat-software` | ซอฟต์แวร์-แอป | แล็ปท็อปกับหน้าต่างแอปกระจกลอยรอบ ๆ |
| `beat-startup` | สตาร์ทอัพ | จรวดพุ่งจากคีย์บอร์ด หางไอพ่นเป็นกราฟขาขึ้น |
| `beat-security` | ไซเบอร์ | โล่แม่กุญแจโฮโลแกรมหน้ากำแพงเซิร์ฟเวอร์ |
| `beat-gaming` | เกม | เคส PC พัดลมแดง จอย และ headset |
| `beat-cloud` | คลาวด์ | ก้อนเมฆอนุภาค มี server rack อยู่ข้างใน |
| `beat-policy` | นโยบายเทค | ตาชั่ง: ชิปกับเสาหิน (คำว่า law/gavel ถูก Flow บล็อก) |
| `beat-hardware` | อื่นๆ → **ฮาร์ดแวร์-คอมพิวเตอร์** | ใส่ CPU ลงซ็อกเก็ต ข้างการ์ดจอ (สายหลักของ iHAVECPU) |
| `frame-16x9`, `frame-1x1`, `frame-3x4` | ขอบภาพทุกแบบ | ลายวงจรเรืองแดงรอบขอบ ตรงกลางดำสนิท วางด้วย `mix-blend-mode: screen` ส่วนดำจึงหายไป เหลือแต่ขอบเรืองแสง |
| `tex-panel` | แผงข้อความ (1:1, 4:5, card) | พื้นคาร์บอนดำลายหกเหลี่ยม เส้นวงจรแดงที่ขอบ |
| `tex-breaking` | พื้นหลังข่าวด่วน | เส้นแสงแดงวิ่งแนวนอน |

- ภาพดิบ: `D:\AI-ART\BotPress\brand\ihc-press\news-art\` · ภาพที่ใช้ render (ย่อแล้ว): `tools\news-art\assets\`
- สร้างใหม่: `node D:\SalmonRK\BotPress\tools\gen-news-art.mjs D:\AI-ART\BotPress\brand\ihc-press\news-art [id ...]` แล้ว `python tools\news-art\prepare-assets.py`
- ⚠ เหมือนตอนทำอวาตาร์: Flow อาจส่งภาพช้าจนภาพเลื่อนไฟล์ **ต้องเปิดดู contact sheet ทุกครั้ง** รอบนี้ beat-hardware ได้ภาพ hero เก่า (stale grab) และภาพหลังจากนั้นเลื่อนไป 1 ตำแหน่งจนถึงท้ายชุด ต้องเปลี่ยนชื่อไฟล์ตามภาพจริงแล้วสั่งสร้างใหม่ 3 ภาพ
- ⚠ แม้สั่ง "no letterbox bars" Flow ก็ยังใส่แถบดำบนล่างให้ภาพฮาร์ดแวร์ `prepare-assets.py` จึงตัดแถบดำให้เอง เฉพาะเมื่อมีแถบที่เรียบทั้งด้านบนและด้านล่าง (ท้องฟ้ามืดที่เว้นไว้วางข้อความจะไม่ถูกตัด)
- ⚠ เฟรมต้องบางและชิดขอบ: เฟรม 1:1 รอบแรกหนาและอยู่ลึกเข้ามาจนบังภาพ จึงแก้ prompt เป็น "hugging the very outer edge … outer five percent" (ภาพที่ไม่ใช้เก็บไว้เป็น `_*.jpg`)
- ภาพจาก Flow มีขนาด 1376×768 (16:9) ภาพ 16:9 ขนาด 1600×900 จึงถูกขยายเล็กน้อย ซึ่งยังคมพอสำหรับโซเชียล

## 4.1 บทเรียนตอนทำเทมเพลต

- **วัดว่าหัวข่าวพอดีด้วยการนับบรรทัด** ไม่ใช่เทียบ `scrollHeight` เพราะสระบนและล่างของไทยยื่นพ้นกรอบบรรทัด ทำให้ `scrollHeight` เกินเสมอ หัวข่าวจึงถูกย่อจนเล็กสุดทุกภาพ
- **ถ่ายภาพผ่าน DevTools protocol** (ตั้งขนาด viewport → รอให้ `document.title` เป็น `ready` → `Page.captureScreenshot`) เพราะ `msedge --screenshot` ถ่ายก่อนวาดครบ จนบางภาพมีแถบขาวด้านล่าง วิธีใหม่ทำ 3 ขนาดเสร็จในราว 2 วินาที
- รอโหลดฟอนต์ด้วย `document.fonts.load(...)` ก่อนวัดขนาด (`fonts.ready` อย่างเดียวอาจเสร็จก่อนเบราว์เซอร์จะขอฟอนต์ด้วยซ้ำ)
- `url('...')` ใน `style="..."` ต้องใช้ single quote · ข้อมูลข่าวที่ฝังใน `<script>` ต้องแปลง `<` เป็น `\u003c` (ทดสอบด้วยหัวข่าวที่มี `</script>` แล้วแสดงเป็นข้อความปกติ)

## 6. ที่ยังไม่ได้ทำ (ขั้นต่อไป)

1. **ปุ่มในแอป:** ในหน้าโต๊ะข่าว เพิ่มปุ่ม "สร้างภาพข่าว" ที่การ์ดข่าวสถานะ ready/published ให้แอป (C#) เรียก `render.mjs` แล้วแสดงภาพ ตอนนี้ต้องสั่งผ่านคำสั่ง
2. **ให้ฝ่ายภาพเลือก variant และภาพเอง:** เพิ่มช่องในบรีฟภาพ เช่น `variant: breaking` และ `art: <ไฟล์>` ให้ render อ่านจากบรีฟ
3. ภาพประกอบเฉพาะข่าว (สร้างจาก Flow ต่อข่าว) ต้องเปิด Chrome Canary ที่ล็อกอิน Flow ไว้ จึงยังทำแบบอัตโนมัติไม่ได้ ตอนนี้ใช้ภาพประจำสายข่าว หรือภาพที่มากับข่าว (`--art`)
