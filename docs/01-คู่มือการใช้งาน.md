## 1. BotPress คืออะไร

แอป Windows ที่จำลอง **กองบรรณาธิการข่าวไอทีและ AI ภาษาไทย** โดยใช้บอท AI 15 ตัว บอทหาข่าว เขียน ตรวจ และเกลาเองตามตารางเวลา **คุณมีหน้าที่แค่อ่านแล้วอนุมัติก่อนเผยแพร่** ข่าวที่ผ่านจะถูกบันทึกเป็นไฟล์ Markdown

**ไม่มี:** เว็บไซต์ข่าว, การโพสต์โซเชียลจริง (มีแค่ร่างข้อความ) และการสร้างภาพจริง (มีแค่บรีฟภาพ)

## 2. ทีมบอท 15 ตัว

| ฝ่าย | บอท | หน้าที่ |
|---|---|---|
| กองบรรณาธิการ | `บก.บห.` | ด่านสุดท้าย เป็นบอทตัวเดียวที่ขอเผยแพร่ได้ |
| | `หัวหน้าข่าว` | ประชุมข่าว คัดเรื่อง มอบหมายงาน และตามงานที่ค้าง |
| ฝ่ายข่าว (8 สาย) | นักข่าว AI · Gadget · ซอฟต์แวร์ · สตาร์ทอัพ · ไซเบอร์ · เกม · คลาวด์ · นโยบายเทค | หาข่าว เสนอข่าว และเขียนข่าวในสายของตัวเอง |
| ฝ่ายตรวจและผลิต | `ผู้ตรวจข่าว 1` (AI, Gadget, ซอฟต์แวร์, สตาร์ทอัพ, อื่นๆ) · `ผู้ตรวจข่าว 2` (ไซเบอร์, เกม, คลาวด์, นโยบาย) | เปิดทุกลิงก์ตรวจข้อเท็จจริง ถ้าไม่ผ่านส่งกลับให้นักข่าว |
| | `บก.ต้นฉบับ` | เกลาภาษาและพาดหัว (ไม่เกิน 90 ตัวอักษร) |
| | `ฝ่ายโซเชียล` · `ฝ่ายภาพ` | ร่างโพสต์ (สั้นไม่เกิน 280 ตัวอักษรและแบบยาว) และบรีฟภาพ 4 บรรทัด |

## 3. ขั้นตอนข่าว

```
เสนอข่าว → มอบหมาย → กำลังเขียน → ตรวจข้อเท็จจริง → เกลาต้นฉบับ → รอ บก.บห. → [คุณอนุมัติ] → เผยแพร่แล้ว
                         ▲               │ ไม่ผ่าน         │ ปัญหาใหญ่
                         └───────────────┴─────────────────┘
ทุกขั้นที่ยังไม่จบ → "ไม่ใช้" (killed)
```

ระบบ (โต๊ะข่าว) บังคับลำดับเอง บอทข้ามขั้นไม่ได้ เมื่อถึง "รอ บก.บห." **เนื้อหาจะถูกล็อก** ข้อความที่คุณอนุมัติจึงตรงกับที่จะเผยแพร่ทุกตัวอักษร

## 5. แหล่งข่าวมาจากไหน

- **ไม่มีรายชื่อแหล่งข่าวตายตัว, RSS หรือ API ข่าว** นักข่าวแต่ละตัว **ค้นเว็บเองด้วย Chrome ในคอมพิวเตอร์ของตัวเอง** (container ของ Rakazo) โดยทำตามกติกาใน prompt (`seed-bots.mjs`)
- กติกาหลัก
  - หาเรื่องใหม่ภายใน 48 ชั่วโมง
  - เปิดอ่านแหล่งต้นฉบับ เช่น ประกาศของผู้ผลิตหรือหน่วยงาน งานวิจัย หรือเอกสารทางการ
  - ข้อสำคัญต้องมาจากแหล่งทางการ 1 แหล่ง หรือแหล่งอิสระ 2 แหล่ง ถ้าไม่ครบต้องเขียนว่า "ยังไม่ยืนยัน"
  - ห้ามคัดลอกบทความ ยกคำพูดตรงได้ไม่เกิน 1 ประโยค
- กติกาเฉพาะสาย
  - Gadget: ราคาต้องมาจากผู้ผลิตหรือผู้จำหน่ายในไทย
  - นโยบาย: ต้องลิงก์ไปที่เอกสารกฎหมายตัวจริง
  - ไซเบอร์: ห้ามเขียนวิธีโจมตี
- ผู้ตรวจข่าวจะเปิดทุกลิงก์ซ้ำแล้วเทียบทีละข้อ ทุกข่าวมีรายการแหล่งอ้างอิงครบ
- ⚠ คุณภาพแหล่งข่าวขึ้นกับโมเดล ไม่ได้กำหนดว่าใช้ search engine ไหน **อ่านแหล่งอ้างอิงก่อนกดอนุมัติทุกครั้ง**
- งานพัฒนาที่แนะนำ: เพิ่มรายชื่อแหล่งข่าวที่เชื่อถือได้ต่อสาย หรือทำเครื่องมือดึง RSS

## 6. วิธีใช้งานประจำวัน

1. **เปิดโปรแกรม: ดับเบิลคลิก `D:\AI-ART\BotPress\BotPress.bat`** (ควรเปิดก่อน 07:00 และเปิดทิ้งไว้)
   - ตรวจ port 5173 / 3110 ทั้งฝั่ง Windows และ WSL ถ้าโปรแกรมอื่นใช้อยู่ (เช่น Vite ของ `D:\SalmonRK\Card`) **จะย้ายไป port ว่างเองและเด้งแจ้งเตือน**
   - เริ่ม WSL, Rakazo และโต๊ะข่าว ตรวจว่า OpenThai บน Spark พร้อม แล้วจึงเปิดแอป
   - บันทึก log ไว้ที่ `D:\AI-ART\BotPress\localai\logs\launcher.log`
   - ⚠ **อย่าเปิด `BotPress.exe` ตรง ๆ** เพราะ port อาจไม่ตรงกับที่ Rakazo ใช้อยู่
   - `BotPress.bat dev` ใช้เปิด devtools (port 9224) สำหรับ seed และการทดสอบ
2. **หน้าแรก** แสดงแถบข่าวด่วน การ์ดสรุปจำนวนเรื่องแต่ละขั้น (ช่อง "รอ บก.บห." เป็นสีเตือนเมื่อมีเรื่องรอ) และการ์ดบอท กดการ์ดเพื่อแชทกับบอทตัวนั้น
3. **โต๊ะข่าว** เป็นบอร์ด 8 คอลัมน์ (อ่านอย่างเดียว) กรองตามสายได้ กดการ์ดเพื่ออ่านข่าวฉบับเต็มพร้อมประวัติการแก้ ปุ่ม "เปิดโฟลเดอร์ข่าว" เปิดโฟลเดอร์ `news\`
4. **อนุมัติข่าว** (สำคัญที่สุด)
   1. ศูนย์งาน → แท็บ **"รอคุณ"** → จำพาดหัวไว้
   2. กด "ดูข่าวที่รอเผยแพร่" แล้วเปิดเรื่องนั้นในคอลัมน์ "รอ บก.บห." อ่าน **เนื้อข่าว แหล่งอ้างอิง และผลตรวจ**
   3. ถ้าผ่าน กด **"อนุญาตครั้งนี้"** ถ้าไม่ผ่าน กด **"ปฏิเสธ"** แล้วพิมพ์บอก `บก.บห.` ว่าต้องแก้อะไร
   4. ถ้าการ์ดของเรื่องเดียวกันขึ้นซ้ำ 2 ใบ ให้อนุมัติใบแรกและ **ปฏิเสธใบที่สอง** ห้ามปล่อยค้างไว้
5. **ศูนย์งาน** มี 6 แท็บ: รอคุณ · กิจกรรม (การทำงานที่กำลังรันอยู่) · งานประจำ (ตารางเวลา และปุ่ม "รันเลย") · ความจำ (`MEMORY.md` ของบอทแต่ละตัว) · ผลงาน · ค่าใช้จ่าย (โมเดลบน Spark ไม่มีค่าใช้จ่าย)
6. **แชทและห้อง**: เรียกบอทในห้องด้วย `@ชื่อ` หรือ `@everyone` แนบไฟล์ได้ครั้งละ 4 ไฟล์ ไม่เกิน 10 MB และพูดแทนพิมพ์ได้ด้วยปุ่ม 🎤
7. **คอมพิวเตอร์ของบอท**: ในหน้าแชท กด Computer เพื่อดูหน้าจอบอทสด ๆ (และเข้าไปควบคุมเองได้) หรือกด Terminal เพื่อเปิด bash ของบอท
8. **Monitor**: ดู GPU/CPU/RAM ของเครื่องนี้, สถานะ LLM (Spark) และ Rakazo, รายการ container และ log ปุ่มเปิดหรือปิด LLM ใช้ไม่ได้ เพราะ LLM อยู่บนเครื่องอื่น
9. **ไฟล์ข่าวที่เผยแพร่แล้ว** อยู่ที่ `D:\AI-ART\BotPress\data\news\<YYYY-MM-DD>\<id>.md` ประกอบด้วยเนื้อข่าว บรีฟภาพ แหล่งอ้างอิง ข้อความโซเชียล และผลตรวจ ต้องนำไปโพสต์ต่อเอง

## 7. ปิดโปรแกรมและเรื่องที่ควรรู้

- กดปิดหน้าต่าง = ออกจากแอป แต่ Rakazo และตารางงานใน WSL อาจยังทำงานต่อ ถ้าต้องการหยุดแน่นอน ให้กด "หยุด" Rakazo ใน Monitor หรือสั่ง `wsl --terminate Ubuntu-24.04`
- ถ้าเปิดแอปแล้ว LLM ไม่พร้อม (เช่น DGX เพิ่ง reboot) ต้องให้ผู้ดูแลเปิด **OpenThai 2.0 (tensorfold, port 8001)** ใหม่ เพราะตัวนี้ไม่เปิดเองหลัง reboot
- **สำรองข้อมูล** ให้ครบทั้ง 3 อย่าง:
  - โฟลเดอร์ `news\`
  - `%LOCALAPPDATA%\BotPress\owner.json` (ถ้าหายจะล็อกอินเข้าบัญชีนี้ไม่ได้อีก)
  - ผลจาก `env BP_NEWS=/mnt/d/AI-ART/BotPress/data/news BP_INFRA=/mnt/d/AI-ART/BotPress/localai bash /mnt/d/AI-ART/BotPress/app/botpress.sh backup` (ฐานข้อมูลของ Rakazo)
