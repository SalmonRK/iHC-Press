## เมื่อ DGX ว่างแล้ว (ขั้น 13 ขึ้นไป)

```bash
# 1) เช็กว่า Spark ว่าง
curl -s http://100.97.194.95:8001/health        # busy:false, requests_running:0
# 2) เปิดแอปด้วย devtools แล้ว seed
D:/AI-ART/BotPress/BotPress.bat dev      # เปิดผ่าน launcher เสมอ (ตรวจ port + เริ่ม Rakazo)
cd D:/botpress && node seed-bots.mjs --dry && node seed-bots.mjs
# 3) ทดสอบสั้น ๆ ก่อน: แชทกับ "นักข่าว AI" ในแอป 1 ข้อความ แล้วดูว่าตอบเป็นภาษาไทยและเรียกเครื่องมือโต๊ะข่าวได้
# 4) ค่อยรัน e2e และ newsroom-live
```

ถ้าต้องหยุดชั่วคราวไม่ให้งานไปที่ Spark: ศูนย์งาน → งานประจำ → ปิด routine ทั้งหมด หรือปิด Rakazo จาก Monitor

## ข้อควรรู้

- **คอมพิวเตอร์ของบอท** (container ต่อบอท) ใช้ image `ghcr.io/elie222/rakazo/computer:v0.1.6` แทน image ภาษาไทย `botteam/computer:v0.1.6-th` ของผู้เขียน ถ้าบอทพิมพ์ภาษาไทยในเบราว์เซอร์แล้วฟอนต์เพี้ยน อาจต้องติดตั้งฟอนต์ไทยเพิ่ม (ยังไม่ได้ทดสอบ)
- ข้อความ toast ตอนสลับเป็นโหมด 🖥 Local ยังเขียนว่า "ข้อมูลไม่ออกนอกเครื่อง" แต่ตอนนี้ข้อมูลไปที่ Spark ผ่าน tailnet แล้ว
- ขณะที่แอปเปิดอยู่ Monitor จะเรียก `/health`, `/v1/models` และ `/metrics` ของ Spark ทุกไม่กี่วินาที ใช้ทรัพยากรน้อยมาก แต่ถ้าไม่อยากให้มี traffic เลย ให้ปิดแอป
- เปิดแอปแล้ว autostart จะเริ่ม Rakazo ให้เอง ตอนปิดแอปยังไม่ได้ตรวจว่า process keepalive `sleep infinity` จะหยุดตามหรือไม่ ถ้าไม่หยุด Rakazo และ routine จะยังทำงานต่อ (เหมือน README ต้นฉบับ) **ถ้าต้องการให้หยุดแน่นอน ให้กด "หยุด" Rakazo ใน Monitor หรือสั่ง `wsl --terminate Ubuntu-24.04`**

### งานที่ต้องทำเพื่อแปลงเป็น iHC-Press (หลังได้รับอนุญาต)

1. **แก้บั๊กบทบาทในโต๊ะข่าว** (พบจากการทดสอบ ดู 06): `newsdesk/server.mjs` ต้องจำกัดว่าบอทตัวไหนย้ายสถานะไหนได้
2. เปลี่ยนชื่อและแบรนด์: ชื่อแอปและหน้าต่าง, โลโก้, ไอคอน, ภาพหัว (`assets/src` → `tools/make-assets.py`), ชื่อ "ลุงจืด" ใน prompt (`seed-bots.mjs`), `owner@botpress.local` และ `%LOCALAPPDATA%\BotPress`
3. ปรับสายข่าวและรายชื่อแหล่งข่าวให้ตรงกับแนวของ iHAVECPU
4. แยก path ที่เขียนตายตัว (`D:\botpress`, `D:\localai`) ออกเป็นค่าตั้งได้ แล้วเลิกใช้ junction
