## 2. แนวคิดภาพ iHC-Press

- **มาสคอตหุ่นยนต์ตัวเดียวกันทั้งทีม** แยกบทบาทด้วยพร็อพ ความคงเส้นคงวาของตัวละครทำให้จำแบรนด์ได้
- ตัวหุ่น: ผิวดำด้าน, หน้ากากดำมัน, **ตา LED สีแดง `#C81E23`**, **ลายวงจรสีแดงบนหัว** (อ้างถึง "CPU" ลายวงจรในโลโก้แม่), เสาอากาศปลายแดง
- สไตล์: **3D animation แนวภาพยนตร์ Pixar/DreamWorks** แสงนุ่ม พื้นหลังเทาอ่อน และมี rim light สีแดง
- **ไม่มีตัวอักษรในภาพ** (เลี่ยงตัวอักษรเพี้ยน) และ **ไม่ใช้ใบหน้าคนจริง**

## 5. งานแบรนด์ที่ยังเหลือ

1. เปลี่ยนชื่อในแอปจาก "BotPress / สำนักข่าวบอท" เป็น **"iHC-Press"** และเลือก tagline (เช่น "ข่าวเทค ข่าวคอม จากเพื่อนคนรักคอม")
2. ปรับสีใน `ui/app.css` / `ui/chat.css` ให้ตรง palette (`#C81E23` และ neutral) และใช้ฟอนต์ Noto Sans Thai
3. เปลี่ยนสายข่าวให้เน้น **คอมพิวเตอร์และฮาร์ดแวร์** (CPU, GPU, PC build, โน้ตบุ๊ก) ตามแนว iHAVECPU
4. ใส่เครดิต "ต่อยอดจาก BotPress โดย jaturapornchai (ลุงจืด)" ในหน้า About หรือ README
5. (ถ้าต้องการ) ใช้ `veo3.mjs` ทำคลิป 3D สั้นของมาสคอตสำหรับโซเชียล ซึ่ง **ใช้เครดิต** ต้องขออนุมัติก่อน
