## 3. หน้าตั้งค่า (ใหม่ 2026-10-16)

เปิดจากเมนูซ้ายล่าง **ตั้งค่า** (ข้างเมนูมีชื่อโมเดลที่ใช้อยู่) รายละเอียด UX และผลทดสอบอยู่ใน [09](09-หน้าตั้งค่า-แหล่งข่าว-YouTube.md)

| แท็บ | ฟีเจอร์ | สถานะ |
|---|---|---|
| **สมอง AI** | การ์ดโปรไฟล์ LLM ตรวจเครื่องปลายทางสด (พร้อม/ไม่พร้อม, เวลาตอบ, เหตุผล) | ✅ |
| | "ใช้โปรไฟล์นี้" → แอปเปิดใหม่เอง ~15–21 วินาที บอททุกตัวเปลี่ยนโมเดลตาม | ✅ ทดสอบ qwen → gemma4 → qwen |
| | เพิ่ม/แก้/ลบโปรไฟล์ · "ตรวจและดึงโมเดล" จาก IP:port · ลบโปรไฟล์ที่ใช้อยู่ไม่ได้ | ✅ |
| **แหล่งข่าว** | รายการแหล่งข่าว (ชื่อ, URL, ชนิด, สายข่าว, หมายเหตุ, เปิด/ปิด) ที่ `news\sources.json` | ✅ |
| | ปุ่ม "ใส่ชุดเริ่มต้น" 35 แหล่ง (newsroom ผู้ผลิต, สื่อฮาร์ดแวร์, ช่อง iHAVECPU, ช่อง YouTube PC 10 อันดับ) | ✅ |
| | ค้นหา, กรองตามสาย/ชนิด, เดาชนิดจากลิงก์อัตโนมัติ | ✅ |
| | บอทอ่านรายการผ่านเครื่องมือ `list_sources(beat)` | ⚠ อยู่ในคำอธิบายเครื่องมือเท่านั้น ยังไม่ได้ใส่ใน prompt ของ routine |
| **YouTube · NotebookLM** | วางลิงก์คลิป → สรุปไทย + ประเด็นพร้อมเวลา + ภาพหน้าจอ ณ เวลานั้น + มุมข่าว + ข้ออ้างที่ต้องตรวจ | ✅ คลิป 17–27 นาที ใช้ 15–30 วินาที |

| | บอทขอสรุปเองผ่าน `youtube_digest(url, by)` (คิวไฟล์ แอปหยิบทุก 15 วินาที) | ✅ ต้องเปิดแอปไว้ |
| | ตรวจเครื่องมือ (node, yt-dlp, ffmpeg, uv, notebooklm) + ปุ่มติดตั้ง/ล็อกอิน NotebookLM | ✅ |

## 5. ข้อจำกัดที่รู้แล้ว (Known issues)

| เรื่อง | ผลกระทบ | ทางเลี่ยงตอนนี้ |
|---|---|---|
| โต๊ะข่าวไม่ตรวจบทบาท | บอทอาจย้ายสถานะที่ไม่ใช่หน้าที่ (เช่น ฝ่ายภาพตีกลับเรื่องที่รอเผยแพร่) | อ่านประวัติเรื่องก่อนอนุมัติ |
| Deadlock ขั้นเกลา (โซเชียล/ภาพไม่มี routine) | เรื่องค้างที่ `editing` | ส่งข้อความหาฝ่ายโซเชียลเอง หรือ "รันเลย" งานของ บก.ต้นฉบับ ([12](12-Cookbook-สูตรใช้งาน.md) สูตร 9) |
| context 64K บน Ollama | สั้นกว่า OpenThai (128K) | ตั้ง `OLLAMA_CONTEXT_LENGTH` บน LocalAI-07 แล้วแก้ `contextWindow` ให้ตรง |
| DGX (LocalAI-08) ออฟไลน์ตั้งแต่ 2026-10-14 และ tensorfold ไม่เปิดเองหลัง reboot | ใช้ OpenThai ไม่ได้ | ใช้ qwen3.6 บน LocalAI-07 |
| qwen3.6 ปนคำจีน/เวียดนามในข้อความไทยบางครั้ง | ข้อความสรุปเพี้ยน | yt-digest ตรวจแล้วเขียนใหม่ให้ · ข่าวยังต้องผ่านคนอนุมัติ |
| image คอมพิวเตอร์บอทไม่ใช่ฉบับภาษาไทย | ฟอนต์ไทยในเบราว์เซอร์บอทอาจเพี้ยน | ยังไม่ได้ทดสอบ |
