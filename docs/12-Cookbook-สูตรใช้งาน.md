## 1. สลับโมเดล LLM ในคลิกเดียว

1. เมนูซ้ายล่าง **ตั้งค่า** → แท็บ **สมอง AI**
2. ดูการ์ดโปรไฟล์ที่ต้องการว่าขึ้น **พร้อม** (ถ้า "ไม่พร้อม" จะบอกเหตุผล เช่น เครื่องปิด)
3. กด **ใช้โปรไฟล์นี้** → อ่านหน้ายืนยัน → ยืนยัน
4. แอปปิดแล้วเปิดใหม่เองใน ~20 วินาที → ตรวจที่ Monitor ว่าการ์ด LLM เป็นชื่อโมเดลใหม่

> ใช้ได้เมื่อโหมดมุมซ้ายล่างเป็น **Local** · งานที่กำลังรันอยู่ตอนสลับจะทำต่อด้วยโมเดลเดิมจนจบ

## 2. เพิ่มเครื่องหรือโมเดลใหม่

**ในแอป (แนะนำ):** ตั้งค่า → สมอง AI → การ์ด **เพิ่มเครื่องหรือโมเดล**

1. ใส่ URL ของเซิร์ฟเวอร์ (ไม่ต้องมี `/v1`) แล้วกด **ตรวจและดึงโมเดล**
2. เลือกโมเดลจากรายการ ตั้งชื่อที่แสดง
3. ตั้ง **context window** ไม่เกินค่าที่เซิร์ฟเวอร์ตั้งไว้จริง (Ollama ค่าเริ่มต้นของเครื่อง LocalAI-07 = 65536) และ max tokens (ปกติ 16384)
4. บันทึก แล้วใช้ตามสูตร 1

| ตัวอย่างเครื่อง | URL | หมายเหตุ |
|---|---|---|
| Ollama LocalAI-07 | `http://100.125.52.66:11434` | ใช้อยู่ · qwen3.6:35b-a3b, gemma4:31b ฯลฯ |
| tensorfold DGX (OpenThai 2.0) | `http://100.97.194.95:8001` | ctx 131072 · ต้องเปิด tensorfold เองหลัง reboot |
| Ollama DGX | `http://100.97.194.95:11434` | มี qwen3.6:35b-a3b, gemma4:31b, openthai-1.6-72b · **เครื่องใช้ร่วม ถามก่อน** |

**เขียนไฟล์เอง:** วาง `.json` ใน `D:\AI-ART\BotPress\localai\llm-profiles\` แล้วการ์ดจะขึ้นในแอป

```json
{
  "remote": true,
  "healthUrl": "http://100.125.52.66:11434",
  "provider": "local",
  "baseUrl": "http://100.125.52.66:11434/v1",
  "modelId": "gemma4:31b",
  "label": "Gemma4 31B (Ollama / LocalAI-07)",
  "apiKey": "local-no-auth",
  "contextWindow": 65536,
  "maxTokens": 16384,
  "vision": true
}
```

## 3. เพิ่ม/ปิดแหล่งข่าว

1. ตั้งค่า → **แหล่งข่าว** (ถ้ารายการว่าง กด **ใส่ชุดเริ่มต้น** ได้ 35 แหล่ง หรือ **เพิ่มเอง**)
2. **เพิ่มแหล่งข่าว** → ใส่ชื่อและ URL (ระบบเดาชนิดให้ เช่น ลิงก์ youtube.com → YouTube)
3. เลือกสายข่าว (ไม่เลือก = ทุกสาย) · ใส่ **หมายเหตุสำหรับบอท** เช่น "ใช้เฉพาะประกาศราคาไทย" หรือ "ข่าวลือ ต้องยืนยันกับผู้ผลิต"
4. บันทึก มีผลทันทีกับการเรียก `list_sources` ครั้งถัดไป
5. ปิดชั่วคราว: กดสวิตช์ที่แถวนั้น (ไม่ต้องลบ)

> ไฟล์จริงคือ `D:\AI-ART\BotPress\data\news\sources.json` · ชุดเริ่มต้นอยู่ที่ `newsdesk\sources-default.json`

## 4. สรุปคลิป YouTube + ภาพหน้าจอเพื่อทำข่าว

1. ตั้งค่า → **YouTube · NotebookLM**
2. วาง **ลิงก์คลิป** (ไม่ใช่ลิงก์ช่อง) → **สรุปคลิป** · รอ 15–30 วินาทีสำหรับคลิป 20–30 นาที
3. ได้: สรุปภาษาไทย · ประเด็นสำคัญพร้อมเวลา (กดเวลาเพื่อเปิดคลิป ณ จุดนั้น) · ภาพหน้าจอต่อประเด็น · มุมข่าว · ข้ออ้างที่ต้องตรวจ
4. **เปิดโฟลเดอร์** เพื่อเอาภาพ `frames\*.jpg` และ `digest.md` ไปใช้
5. ก่อนใช้ในข่าว:
   - ตรวจข้ออ้างในหัวข้อ "ต้องตรวจ" กับแหล่งต้นทาง (ผู้ผลิต/เบนช์มาร์กตัวจริง)
   - **ใส่เครดิตช่องและลิงก์คลิปทุกครั้ง** ภาพหน้าจอเป็นของเจ้าของช่อง

ผลเก็บที่ `D:\AI-ART\BotPress\data\news\youtube\<videoId>\` (`digest.json`, `digest.md`, `transcript.txt`, `frames\`) · กดสรุปคลิปเดิมในแอป = สรุปใหม่ทับผลเดิม (ส่วนบอทที่ขอคลิปที่มีผลแล้วจะได้ผลเดิมทันที)

## 5. สั่งให้บอทสรุปคลิปเองแล้วเขียนข่าว

แชทกับนักข่าวสายที่เกี่ยวข้อง (เช่น นักข่าว Gadget):

```
ช่วยดูคลิปนี้ https://www.youtube.com/watch?v=8xxZyaXUuP4
ใช้ youtube_digest สรุปก่อน (ถ้าได้ pending ให้รอแล้วเรียกซ้ำ)
แล้วเสนอข่าวด้วย pitch_story ถ้ามีประเด็นใหม่ ใส่ลิงก์คลิปและชื่อช่องใน sources
```

- บอทเรียก `youtube_digest` ครั้งแรกได้ "pending" → แอปบนเครื่องนี้หยิบไปทำภายใน 15 วินาที → เรียกซ้ำได้ผล (~30 วินาทีรวม)
- **แอป iHC-Press ต้องเปิดอยู่** เพราะคอมพิวเตอร์ของบอทรัน yt-dlp เองไม่ได้

## 6. เปิดใช้ NotebookLM

> ไม่จำเป็น: ตอนนี้สรุปด้วย LLM (qwen3.6) ได้อยู่แล้ว ใช้ NotebookLM เมื่ออยากได้สรุปจาก Gemini

1. เตรียม **บัญชี Google แยก** สำหรับงานนี้ (ไฟล์ session มีสิทธิ์เต็มของบัญชี)
2. ตั้งค่า → YouTube · NotebookLM → **ติดตั้ง** (= `uv tool install "notebooklm-py[browser]"`)
3. **เข้าสู่ระบบ Google** (= `notebooklm login`) ครั้งแรกดาวน์โหลด Chromium ~170 MB แล้วเปิดหน้าล็อกอิน
4. กด **ตรวจใหม่** → บรรทัด "ตัวสรุปตอนนี้" ต้องเปลี่ยนเป็น NotebookLM
5. สรุปคลิปทดสอบ 1 คลิป ทุกคลิปจะเข้า notebook "iHC-Press · YouTube" (id เก็บใน `news\youtube\notebook.json`)

ข้อจำกัด: notebooklm-py ไม่ใช่ของ Google (API ภายใน เปลี่ยนได้ทุกเมื่อ) · คลิปอายุ < 72 ชม., private, unlisted อาจนำเข้าไม่ได้ · ภาพหน้าจอยังมาจาก yt-dlp + ffmpeg · ถ้าล้มเหลวจะใช้ LLM แทนเอง · ⚠ ส่วนนี้ยังไม่ได้ทดสอบจริง

## 7. สั่งข่าวด่วนนอกตารางเวลา

- **มีประเด็นอยู่แล้ว:** แชทกับนักข่าวสายนั้น "เสนอข่าวเรื่อง … ด้วย pitch_story แหล่งข่าว …" แล้วไป ศูนย์งาน → งานประจำ → หัวหน้าข่าว → **รันเลย** เพื่อให้มอบหมายทันที
- **ให้ทุกสายหาข่าวตอนนี้:** งานประจำ → ประชุมข่าวเช้า (หัวหน้าข่าว) → **รันเลย**
- ขั้นต่อไปเดินตาม routine ถ้าอยากเร่ง กด "รันเลย" งานของเจ้าของขั้นถัดไป (ผู้ตรวจ → บก.ต้นฉบับ → บก.บห.)
- เวลาที่วัดได้ (OpenThai, 10-14): เสนอ → ผ่านตรวจ ~26 นาที, ถึงรอเผยแพร่ ~42 นาที

## 8. ให้นักข่าวใช้รายการแหล่งข่าวทุกรอบ

ตอนนี้คำสั่ง "เรียก `list_sources` ก่อนหาข่าว" อยู่ในคำอธิบายของโต๊ะข่าวเท่านั้น ถ้าอยากให้บอททำทุกครั้ง:

1. แก้ `D:\SalmonRK\BotPress\iHC-Press\seed-bots.mjs` ฟังก์ชัน `reporter` (บรรทัด ~19) ข้อ 1 "หาข่าว" เพิ่มก่อนประโยคแรก:
   `เริ่มด้วย list_sources beat="<สายของคุณ>" แล้วไล่ดูแหล่งในรายการก่อน จากนั้นค่อยค้นเว็บเพิ่ม · ทำตามหมายเหตุของแต่ละแหล่ง ·`
2. ถ้าอยากให้ใช้คลิปได้ด้วย เพิ่ม: `แหล่งชนิด youtube ให้ใช้ youtube_digest กับคลิปใหม่ แล้วใส่ชื่อช่องและลิงก์คลิปใน sources`
3. backup ก่อน (`botpress.sh backup`) แล้วเปิดแอปด้วย `iHC-Press.bat dev`
4. `node seed-bots.mjs --dry` (ตรวจความยาว prompt) แล้ว `node seed-bots.mjs --rewrite`
   - ⚠ `--rewrite` ทับ prompt ที่เคยแก้ในแอปของบอทที่ prompt ต่างจาก seed
5. ทดสอบ: แชทนักข่าว Gadget "หาข่าวการ์ดจอวันนี้ 1 เรื่อง" แล้วดูใน กิจกรรม ว่ามีการเรียก `list_sources`

## 9. แก้เรื่องค้างที่ขั้นเกลา (deadlock)

อาการ: เรื่องอยู่ `editing` นาน บันทึกของ บก.ต้นฉบับ บอกว่ารอฝ่ายโซเชียลหรือฝ่ายภาพแก้

1. เปิดเรื่องในโต๊ะข่าว อ่าน note ล่าสุดว่าต้องแก้อะไร
2. แชทหา **ฝ่ายโซเชียล** (หรือ **ฝ่ายภาพ**): `เรื่อง <รหัส> ช่อง social ต้องแก้: <ข้อความจาก note> ใช้ get_story แล้ว update_story แก้ช่อง social`
3. ศูนย์งาน → งานประจำ → บก.ต้นฉบับ → **รันเลย** ให้ตรวจซ้ำแล้วย้ายเป็น `ready`
4. ทางแก้ถาวร (ยังไม่ได้ทำ): เพิ่ม routine กวาดงานให้ฝ่ายโซเชียลและฝ่ายภาพใน `ROUTINES` ของ `seed-bots.mjs`

## 10. ขยาย context ของ Ollama

ค่า 64K มาจากฝั่ง Ollama ปรับต่อคำขอผ่าน API แบบ OpenAI ไม่ได้

1. **ขอเจ้าของ LocalAI-07 ก่อน** (ใช้ VRAM เพิ่ม และกระทบคนอื่นที่ใช้ร่วม)
2. บน LocalAI-07 ตั้ง environment `OLLAMA_CONTEXT_LENGTH=131072` แล้วรีสตาร์ท Ollama
3. ตรวจ `curl.exe -s http://100.125.52.66:11434/api/ps` หลังมีคำขอ ว่า `context_length` เป็นค่าใหม่
4. แก้ `contextWindow` ในโปรไฟล์ (ตั้งค่า → สมอง AI → แก้ไข) ให้ **เท่ากับ** ค่านั้น แล้วใช้โปรไฟล์ใหม่
5. ห้ามตั้ง `contextWindow` เกินค่าจริง เพราะ Ollama จะตัด prompt เงียบ ๆ

## 11. สรุปคลิปจาก command line

```powershell
cd D:\SalmonRK\BotPress\iHC-Press
node tools\yt-digest.mjs "https://www.youtube.com/watch?v=d2hGLaQQpUk"                 # ค่าเริ่มต้น: engine auto, 6 ภาพ
node tools\yt-digest.mjs "<url>" --engine llm --frames 8 --out D:\tmp\yt                 # บังคับใช้ LLM, 8 ภาพ, โฟลเดอร์อื่น
node tools\yt-digest.mjs "<url>" --engine notebooklm                                     # บังคับ NotebookLM (ต้องล็อกอินก่อน)
```

ใช้ LLM จาก `llm.json` ตัวเดียวกับบอท · ต้องมี `yt-dlp` และ `ffmpeg` ใน PATH

## 12. เพิ่มเครื่องมือใหม่ให้โต๊ะข่าว

1. เพิ่ม entry ใน `const TOOLS = { … }` ของ `newsdesk/server.mjs` (ดูตัวอย่าง `list_sources` ที่บรรทัด ~269): `description` ภาษาไทย, `inputSchema` ด้วย `S({...}, [required])`, และ `run(d, a)` คืนข้อความ
2. เพิ่ม check ใน `selftest()` แล้วรัน `node newsdesk\server.mjs --selftest`
3. `wsl -d Ubuntu-24.04 -- docker restart botpress-newsdesk`
4. ถ้าบอทควรเรียกเครื่องมือนี้ในงานประจำ ให้เพิ่มใน prompt ของ `seed-bots.mjs` แล้ว `--rewrite` (สูตร 8)
5. ถ้าต้องให้เครื่อง Windows ทำงานแทน (เช่น yt-dlp) ใช้แบบคิวไฟล์เหมือน `youtube_digest`: เขียนคำขอใน `/news/...`, ให้ `Settings.cs` หยิบใน loop 15 วินาที แล้วเขียนผลกลับ

## 14. ทำภาพข่าวพร้อมโพสต์ (artwork)

1. ดู id ข่าวในโต๊ะข่าว (เช่น `20261014-01`)
2. `cd D:\SalmonRK\BotPress\iHC-Press` แล้ว `node tools\news-art\render.mjs --story 20261014-01` → ได้ 16:9, 1:1, 4:5 ใน `D:\AI-ART\BotPress\data\news\art\20261014-01\`

4. ถ้าคำไทยถูกตัดกลางคำ ให้ครอบด้วย `{...}` ในหัวข่าว หรือเพิ่มคำในรายการ `KEEP` ของ `tools\news-art\template.html`
5. รายละเอียดและวิธีสร้างภาพประกอบใหม่: [13](13-Artwork-ข่าว.md)
